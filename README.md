I'm a Full Stack Developer with hands-on experience building **mission-critical systems for public institutions**, where reliability and data integrity aren't optional. I work end-to-end across the **.NET** ecosystem (my core), **Java/Spring Boot**, and the modern **TypeScript** stack — and I care as much about the *why* behind the code as the code itself.
